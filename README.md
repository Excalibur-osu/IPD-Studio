# PID Studio

Open-source, browser-based **intelligent P&ID / instrumentation diagram editor**.
Drag ISA-5.1-style symbols onto a sheet, connect process and signal lines with
proper orthogonal routing, tag instruments with validated ISA tags, and export
real deliverables (SVG/PDF drawing, instrument index, line list).

Local-first: no backend, no login — diagrams live on your machine.

## Development

```bash
npm install
npm run dev    # start the editor
npm test       # run unit tests
```
